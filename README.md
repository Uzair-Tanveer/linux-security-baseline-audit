# Linux Security Baseline Audit Script

## Overview:
This project is a simple Linux security audit tool that checks basic security controls and generates a timestamped report. 

## Purpose: 
The goal of this project is to demonstrate:
-linux command-line familiarity
-security posture review
-simple automation with Python
-basic evidence collection
-documentation and GitHub workflow (with Git)

## Tools Used:
-Linux
-Python 3
-Git
-GitHub
-UFW
-SSH
-ss

## What It Checks:
-firewall status
-SSH root login setting
-SSH service status
-OS Version
-Listening Ports

## Output: 
The Script creates a report file in the 'reports/' folder

## Lessons Learned:
This project helped me practice reviewing basic system security settings and documentation results in a clear and repeatable way!
